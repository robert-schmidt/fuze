# Getting started

This section takes you from nothing to an agent following the signal on a simulated account, with no money and no keys.
It takes a few minutes.

1. [Install](install.md): Python, a virtual environment, and the agent from the repository.
2. [First run in simulation](first-run.md): set your sizing, start the agent, read its status.

Then, when you are ready: [Using it from an AI coding tool](../ai-tools/README.md), and later
[The three modes](../modes/README.md).

Prefer to let your AI coding tool do it? Ask it to "install the FUZE agent and set it up in simulation". The
repository's `AGENTS.md` tells it how, and which steps it must leave to you.
