# Getting started

This section takes you from nothing to an agent following the signal on a simulated account, with no money and no keys.
It takes a few minutes.

1. [Install](install.md): step by step for macOS, Linux and Windows. It explains each program it installs.
2. [First run in simulation](first-run.md): set your sizing, start the agent, read its status.
3. [Connect your AI coding tool](../ai-tools/README.md): one step per tool.

Later, when you are ready: [The three modes](../modes/README.md).

Prefer to let your AI coding tool do all of it? Paste this sentence into it:

```text
Install the FUZE agent from https://github.com/robert-schmidt/fuze and set it up in simulation. Follow the AGENTS.md in that repository.
```

The repository's `AGENTS.md` tells it how, and which steps it must leave to you.
